# ZYZ 雅思阅读题库（IELTS Reading Practice）

纯前端的雅思阅读练习题库，包含 **281 篇阅读 PDF**、配套的**在线练习网页**，以及 **PASSAGE 离线练习版**。整套内容可离线使用，无需安装软件，支持 Windows / macOS。

---

## 📦 一、快速开始（3 步）

1. 打开本页右上角绿色 **`Code`** 按钮 → 点击 **`Download ZIP`**（约 300MB）
2. 解压到电脑任意文件夹（**不要在压缩包里直接打开**）
3. 双击 `index.html` 用 Chrome / Edge 打开，即可开始练习

> 💡 如果双击后某些页面加载不出来（浏览器对本地文件有安全限制），用下面的「本地服务方式」最稳：

```bash
# 在解压后的文件夹里打开终端 / 命令提示符，执行：
python3 -m http.server 8000
# 然后浏览器访问：http://localhost:8000
```

## 🚨 三、本地文件丢失了？这样恢复

如果你的电脑重装、文件误删或换新电脑，按下面的方法从本仓库完整恢复：

### 恢复练习题库（281 篇 PDF + 练习网页）

1. 打开 **https://github.com/ivy11220911-droid/ZYZ-IELTS-Reading**
2. 点右上角绿色 **`Code`** → **`Download ZIP`**
3. 解压 → 双击 `index.html` 即可使用（或用上面的本地服务方式打开）
4. ✅ 题库内容与原来电脑上的**完全一致**（281 篇 PDF 全部包含）

> 也可以用 git 命令下载（需要装 git）：
> ```bash
> git clone https://github.com/ivy11220911-droid/ZYZ-IELTS-Reading.git
> ```

### ⚠️ 关于学习记录（重要）

**做题记录、笔记、错题本保存在浏览器本地，不在这些文件里！** 所以：

- 文件恢复 ≠ 记录恢复。想保住记录，需要**提前在网页内点击「备份」下载 JSON 备份文件**
- 换电脑 / 重装系统前：先在旧电脑上导出备份（PASSAGE 版：首页底部「备份」或「记录 → 立即完整备份」）
- 新电脑恢复：打开练习网页 → 「记录 → 更多操作 → **恢复学习记录**」→ 选择之前下载的 JSON 文件
- 备份文件请存到网盘 / U 盘 / 邮箱，不要只放在电脑桌面

## ❓ 四、常见问题

**Q：双击 index.html 后页面空白 / PDF 打不开？**
A：浏览器对本地文件有限制。请改用本地服务方式（见第一节），或改用 PASSAGE 离线版单文件网页。

**Q：PDF 只有 281 篇，是不是少了？**
A：不是。仓库内容与原始题库一一对应，281 篇即完整套数。

**Q：网页上的数据会不会上传到服务器？**
A：不会。这是纯前端页面，所有记录只存在你自己的浏览器里。

**Q：手机上能用吗？**
A：可以浏览 PDF，但练习交互建议在电脑上进行，体验更好。
