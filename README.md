# ZYZ 雅思阅读题库（IELTS Reading Practice）

一个纯前端的雅思阅读在线练习题库，包含 **281 篇阅读 PDF** 和配套的在线练习页面。

## 📁 目录结构

```
├── index.html          # 练习页面入口（单文件应用）
├── js/                 # 页面逻辑脚本
├── css/                # 样式文件
├── assets/             # 静态资源
├── ReadingPractice/    # 281 篇雅思阅读 PDF 题目
└── PASSAGE-1011/       # PASSAGE by ZYZ 离线练习网页（2026-10-11-r3 版，81MB 单文件）
```

## 📝 PASSAGE-1011 离线练习版

`PASSAGE-1011/PASSAGE-by-ZYZ-IELTS-Reading-2026-10-11-r3.html` 是一个**自包含的离线练习网页**（学习记录保存在浏览器本地），使用前请先阅读同目录下的 `使用说明.txt`。下载后用 Chrome/Edge 打开即可，无需其他文件。

## 🚀 使用方式

方式一：直接双击打开 `index.html`

方式二：本地起一个静态服务（推荐，加载更稳定）：

```bash
python3 -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

也可以直接用 GitHub Pages 发布后在线访问。

## 📄 许可

题目 PDF 仅用于个人学习备考，请勿商用。
