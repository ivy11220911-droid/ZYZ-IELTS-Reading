# ZYZ 雅思阅读题库（IELTS Reading Practice）· 281 篇

这里放的是 **两个独立的雅思阅读练习产品**：**Atlas** 和 **PASSAGE by ZYZ**。两者都是纯前端离线网页，不用装软件，Windows / macOS 都能用，做题记录只存在你自己的浏览器里。

> 📌 **当前题库：281 篇阅读 PDF**（Atlas 全量收录）｜最近更新：**2026-11-17**（Atlas 更新至 1112 版、PASSAGE 更新至 11-16-r2）｜完整更新记录见文末 [第八节](#八更新记录)

> ⚠️ **先说最重要的一点**：Atlas 和 PASSAGE 是两款**独立**的产品，**学习记录（备份数据）互不互通**。你在 Atlas 里做的题、记的笔记，不会出现在 PASSAGE 里；反过来也一样。所以——**想换版本之前，务必先在原版本里导出 JSON 备份**。

## 一、两个版本有什么区别？该选哪个？

一句话：**Atlas 大而全，PASSAGE 小而精。**

| 对比项 | **Atlas** | **PASSAGE by ZYZ** |
|---|---|---|
| 定位 | 大而全：一个完整的练习站 | 小而精：只做阅读，开箱即用 |
| 形态 | 一个文件夹（`index.html` + `js/` + `css/` + `assets/` + `ReadingPractice/`） | **单个 HTML 文件**，双击就开 |
| 体积 | 约 254MB（808 个文件） | 约 83MB（1 个文件） |
| 题库 | **281 篇阅读 PDF** 全量收录 | 内置阅读题库，单篇练习 + 模考 |
| 功能 | 阅读 + 听力模块、进度统计、词汇阅读器、错题与记录中心 | 单篇练习、模考、成绩记录、复盘笔记、一键完整备份 |
| 打开方式 | 双击 `index.html`；页面加载不全时建议用本地服务方式 | 双击 HTML 直接打开 |
| 适合谁 | 想要一个「什么都有」的完整工作台，愿意多花一步配置 | 想最小成本开练、只想专注阅读、经常换设备 |
| 备份数据 | **独立**，不与其他版本互通 | **独立**，不与其他版本互通 |

**选择建议**

- 只想安安静静刷阅读题 → **PASSAGE**（一个文件，拷到哪都能用）
- 想要题库全量 PDF + 统计 + 词汇工具 + 听力模块 → **Atlas**

## 三、Atlas 快速开始（3 步）

1. 下载 `Atlas-1112.zip`，解压到电脑任意文件夹（**不要在压缩包里直接打开**）
2. 双击 `index.html`，用 Chrome / Edge 打开
3. 从左侧栏选阅读或听力开始练习

> 💡 如果双击后页面空白、PDF 打不开（浏览器对本地文件有安全限制），用本地服务方式最稳：

```bash
# 在解压后的文件夹里打开终端 / 命令提示符，执行：
python3 -m http.server 8000
# 然后浏览器访问：http://localhost:8000
```

## 四、PASSAGE 快速开始（3 步）

1. 下载 `PASSAGE-by-ZYZ-IELTS-Reading-2026-11-16-r2.zip`，**完整解压**到普通文件夹
2. 用 Chrome / Edge 的**普通窗口**打开那个 HTML 文件（不要在压缩包、微信/QQ 或网盘预览里直接打开）
3. 选「单篇练习」或「模考」开始；离开前用页面上的退出/暂停按钮，等待保存完成

> 备份：首页底部「备份」或「记录 → 立即完整备份」，确认下载列表里出现了 JSON 文件。
> 恢复：新版本里「记录 → 更多操作 → 恢复学习记录」→ 选你的备份文件。

## 六、本地文件丢失了？这样恢复

1. 打开 **https://github.com/ivy11220911-droid/ZYZ-IELTS-Reading**
2. 到 **Releases** 页下载你要的版本（或 `Code` → `Download ZIP` 拿 Atlas 源码）
3. 解压即可使用，题库内容与你原来电脑上的完全一致

### ⚠️ 关于学习记录（重要）

**做题记录、笔记、错题本保存在浏览器本地，不在这些文件里！** 所以：

- 文件恢复 ≠ 记录恢复。要保住记录，必须**提前在网页内导出 JSON 备份**
- 换电脑 / 重装系统前：先在旧设备上导出备份（Atlas：记录中心；PASSAGE：首页底部「备份」或「记录 → 立即完整备份」）
- 新设备恢复：打开对应版本 → 「记录 → 更多操作 → 恢复学习记录」→ 选择备份 JSON
- **Atlas 的备份不能导入 PASSAGE，反之亦然**；换版本等于从零开始做题记录
- 备份文件请存网盘 / U 盘 / 邮箱，不要只放在桌面

## 七、常见问题

**Q：Atlas 和 PASSAGE 能互相同步记录吗？**
A：不能。两者是独立产品，备份格式互不通用。换版本前先各自导出备份留档。

**Q：Atlas 双击 index.html 后页面空白 / PDF 打不开？**
A：浏览器对本地 `file://` 有限制，改用第三节的本地服务方式；或者直接用 PASSAGE 单文件版。

**Q：PDF 只有 281 篇，是不是少了？**
A：不是，281 篇即完整套数。

**Q：网页上的数据会上传到服务器吗？**
A：不会。纯前端页面，所有记录只存在你自己的浏览器里。

**Q：手机上能用吗？**
A：可以浏览，但练习交互建议在电脑上进行。
