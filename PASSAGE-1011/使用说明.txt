PASSAGE by ZYZ 使用说明｜2026-10-11-r3

一、更新前先备份
在能看到记录的版本中，进入“记录”，下载完整备份，保留 JSON 文件和旧网页，再打开新版。
新版没有显示旧记录时，在“记录 → 更多操作 → 恢复学习记录”选择自己的备份。升级后请继续使用新版。旧版可能看不到记录；回到新版查看即可，不要清空记录或清理浏览器数据。

二、先解压，再打开
把 ZIP 完整解压到电脑上的普通文件夹，用 Chrome 或 Edge 的普通窗口打开其中的 HTML 网页。
不要在压缩包内直接打开，也不要通过微信、QQ、网盘或系统的预览窗口打开。解压后可离线练习，本版本供电脑使用。

三、平时定期备份
记录保存在当前浏览器中。更换电脑或浏览器、移动网页、清理浏览器数据前，请先下载完整备份。
首页底部点击“备份”，即可下载完整备份；“上次备份下载”显示最近一次下载时间。也可以在“记录”页点击“立即完整备份”。请确认浏览器下载列表里已有 JSON 文件，并妥善保留。
备份之后新增的练习和笔记，需要再次备份才能保留。

四、保存遇到问题
先不要关闭或刷新网页，按弹窗提示重试保存。
仍无法保存时，点击“下载练习文件”，再按提示选择刚下载的文件。网页会自动核对并尝试恢复。成功后，按提示继续作答、重试保存或查看复盘。
仍不能保存时，请留好练习文件。之后在能够正常保存的新版中，从“记录 → 更多操作 → 恢复学习记录”导入：可识别且与当前内容匹配的未完成练习可继续作答；已提交的内容可重试保存，复盘内容可恢复笔记和标注。遇到不匹配提示时，请保留文件和旧版网页，不要清空数据。
“已安全保存”表示学习记录已保存；“内容已保留在练习文件中”表示需要留好文件，之后导入。

五、无法开始练习，或一直保存失败
先使用浏览器普通窗口，关闭其他打开的 PASSAGE 页面，不要清理浏览器数据。
点击“立即完整备份”，或使用故障提示中的备份按钮。网页会优先下载能确认的已保存成绩、复盘和笔记；部分无法确认的未完成内容可能不包含在内。请确认浏览器下载列表中已有 JSON 文件。
按提示点击恢复按钮，或在“记录 → 更多操作 → 恢复学习记录”选择刚下载的文件，确认后等待本页重新打开。核对恢复结果后，可继续练习，原内容会保留。
恢复可能需要一些时间，请勿刷新或关闭本页。若浏览器提示“页面无响应”，请选择“等待”。
有内容未能恢复时，展开“需要帮助？”下载诊断文件发给老师，并继续保留原备份和原网页。也可从“记录 → 更多操作”下载同一份诊断文件。
如果需要先练习，可按启动弹窗提示选择临时练习或模考。结束或中途退出时，会提示下载本次“练习文件”；按提示选择文件核对后再退出。临时练习不会自动加入浏览器中的学习记录，之后可在能正常保存的新版中导入文件。

六、恢复备份
请使用自己的 PASSAGE 备份。在“记录 → 更多操作 → 恢复学习记录”选择文件。显示可恢复数量后，点击一次“确认恢复”，等待页面自动打开记录页，再核对恢复结果。
有少量内容无法恢复时，其他可靠记录仍会恢复，并显示成功与未恢复数量。需要进一步排查时，展开“需要帮助？”下载诊断文件发给老师。全部成功时不显示诊断提示。原备份请继续保留。
本页清空记录后，可重新选择此前保留的备份恢复。没有自己的备份时，先尝试“立即完整备份”或故障提示中的备份按钮；不要清理浏览器数据。
本版本下载的备份，请使用本版本或更新版本恢复。旧版可能无法识别新版备份。
若本页仍无法完成保存，请保留原数据与备份，在能正常保存的浏览器中打开新版并选择自己的备份。换浏览器不会自动带走记录。
如果只想找回某次之前保存的进度，展开对应列表，按篇名、保存时间和状态选择。恢复后查看页面结果；较新的本机学习内容会保留。

七、在其他平台或纸质材料上练习过
其他平台的备份不能直接导入。可在练习页点击“管理练习状态”，选择文章后“标为已练习”；只记录练习进度，不会补入原平台的成绩、用时或笔记。手动标记会随完整备份保存。

八、网页打不开
确认已完整解压、打开的是 HTML 文件，并使用电脑浏览器。仍打不开时，可以重新下载并解压一份，保留原网页和已有备份。换浏览器不会自动带走原浏览器里的记录。

九、答案更新与旧记录
当前版本沿用已核定的 Understanding climate change 多选答案。旧记录保留提交时的答案、成绩、用时和笔记；再次练习使用当前标准答案。

十、当前答题要求
判断、标题匹配与填空等题型的要求已统一，各题的字数、数字、多选和重复使用规则保留。已识别的旧记录保留当时的题面和笔记；再次练习使用本版要求。

十一、下载诊断文件
遇到问题时，在提示窗口或“记录 → 更多操作”点击“下载诊断文件”，确认下载列表中已有 PASSAGE-诊断文件.json，发给老师排查即可。各处入口下载同一种文件。
